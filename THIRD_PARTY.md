# Third-party material

Everything this skill redistributes that is **not** original to it, and everything it
loads from someone else at runtime. Audited 2026-10-01.

The skill's own code, text, templates and generated stills are original work under
AGPL-3.0-or-later (see `LICENSE`, `NOTICE`). They are not repeated here.

`references/music-and-sound.md` and `references/drawing.md` already require recording
third-party licenses *per project*. This file is the same discipline applied to the
skill itself.

### `assets/lib/font5x7.js` — provenance resolved

A 5×7 bitmap font (38 glyphs: digits, uppercase, `G J Q X ! - . , ' >` and a space),
row-major `#`/`.` encoding. The glyphs are **original to this project**, authored for
the 04-pixel-diorama style, where a 5×7 face that scales to whole pixels is the point;
16-cross-stitch reuses it.

It is not transcribed from or copied out of any third-party font table, so no
attribution is owed and no additional terms apply. The file now carries this statement
inline, so a reader of the file alone reaches the same conclusion.

### Generated media (first-party, no third-party license)

- All `assets/styles/*/still.jpg`, `assets/styles/library-sheet.jpg` and
  `assets/patterns/ambient-loop/still.jpg` — output of this skill's own renderer
  (canvas via `scripts/render_page.py`) or its Blender helpers. Verified: no EXIF
  author/copyright tags, and the "photographic" plates (`07-beans-plate.jpg`,
  `11-tactile-macro.jpg`) are 3D renders, not photographs. **No third-party
  photography is bundled.**
- `assets/styles/12-coded-ascii/site/audio/loop.mp3` — 45.7 s, generated by the
  bundled synth (`assets/styles/12-coded-ascii/sound.py` + `lofi.py`) and muxed
  locally with ffmpeg (`TAG:encoder=Lavc62.28`), i.e. no third-party recording.

## 2. Loaded at runtime, not redistributed

Nothing below ships in this repository. Each is fetched from the machine or the network
when a template renders, and each keeps its own license, which travels with the *user's
project*, not with the skill.

- New Python or CLI dependency → add it to §2 with its license.
- If you fork this skill, keep this file and update the audit date.
